# Fantasy War Room

Fantasy War Room is an AI-powered Fantasy Football Draft Assistant built specifically for my keeper league.

## Mission

Help make the best draft decision at every pick by combining:

- League rules
- Draft philosophy
- Player rankings
- ADP
- Projections
- Injuries
- Expert articles
- Keeper information
- Live draft board
- AI reasoning

The system should explain *why* it recommends each player rather than simply listing the highest-ranked player.
